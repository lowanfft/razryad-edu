# РАЗРЯД — интерактивный урок по системам счисления

Образовательный веб-ресурс для изучения систем счисления в 8–9 классах.
Сайт опубликован на GitHub Pages и работает без серверной части.

**Сайт:** https://lowanfft.github.io/razryad-edu/

## Возможности

- Теоретические материалы по шести темам с поиском и фильтрами.
- Интерактивный конвертер между двоичной, восьмеричной, десятичной и шестнадцатеричной системами.
- Двоичный конструктор и практические задания с проверкой ответов.
- Итоговое тестирование из десяти вопросов с пояснениями.
- Анкета обратной связи и просмотр собственных результатов.
- Светлая и тёмная темы; адаптивный интерфейс.

## Технологии

- HTML5: семантические разделы, формы, навигация.
- CSS3: блочная модель, Flexbox, медиазапросы, анимации.
- JavaScript: DOM, события, динамическое формирование элементов, фильтрация данных.
- `localStorage`: локальное сохранение результатов тестов и ответов анкеты.
- Git и GitHub Pages: версионирование и публикация статического сайта.

## Запуск

Откройте `index.html` в браузере или запустите страницу через Live Server в VS Code.
Установка Node.js и дополнительных библиотек не требуется.

## Структура

| Файл или папка | Назначение |
| --- | --- |
| `index.html` | Учебный материал, поиск и интерактивная лаборатория |
| `quiz.html` | Итоговый тест |
| `feedback.html` | Анкета обратной связи |
| `admin.html` | История результатов и отзывов текущего браузера |
| `style.css` | Общие стили и адаптивная вёрстка |
| `js/` | Логика интерфейса, заданий, теста и хранения |

## Хранение данных

Результаты тестов и отзывы сохраняются **локально в `localStorage` браузера**.
Они не отправляются на сервер и не объединяются в общую базу данных.
Историю можно просмотреть на странице `admin.html` в том же браузере и профиле.
Другой человек, пользующийся этим же браузером и профилем, тоже сможет увидеть эти записи.
Очистка данных сайта в браузере удаляет сохранённые записи.
