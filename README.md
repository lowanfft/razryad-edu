# РАЗРЯД — версия для ПР6, GitHub Pages

Готовый **статический** образовательный сайт «Системы счисления».
Сделан на семантическом HTML5, CSS3 (Flexbox, box model, медиазапросы)
и ванильном JavaScript (DOM, события, динамические карточки, живой поиск,
переключение темы, интерактивная лаборатория и итоговый тест).

## Что работает

- Главная `index.html`: 6 тем, фильтры и живой поиск по материалам,
  конвертер чисел, двоичный конструктор и тренажёр.
- `quiz.html`: 10 вопросов, пояснения ответов, сохранение попыток в браузере.
- `feedback.html`: анкета, сохранение ответов в браузере.
- `admin.html`: локальная статистика и история записей **только этого браузера**.
- Тёмная тема, адаптивная вёрстка, доступная навигация.

**Важно:** в этой версии нет серверной БД. `localStorage` работает локально:
преподаватель не получает анкеты с чужих устройств. Данные другого браузера,
телефона или профиля на этой странице не видны. Очистка данных браузера
может удалить записи. Это нормальное ограничение GitHub Pages и не требуется
исправлять для ПР6. Если нужна общая БД, нужен сервер или облачный сервис.

## Локальный запуск

Просто открой `index.html` в браузере, либо используй расширение VS Code
Live Server. Не нужны Node.js, npm, SQLite и отдельная регистрация.
Для демонстрации реалистичного поведения рекомендуется Live Server.

## Публикация по ПР6

У тебя уже существует пустой публичный репозиторий:
https://github.com/lowanfft/razryad-edu

1. Распакуй **содержимое** ZIP в новую папку, открой папку в VS Code.
   Файл `index.html` должен лежать **в корне** проекта, рядом с `style.css`.
2. Установи Git for Windows, если его нет (git-scm.com/downloads/win).
3. В терминале VS Code (PowerShell) последовательно выполни:

   ```powershell
   git init
   git add .
   git commit -m "Initial commit: educational site Razryad"
   git branch -M main
   git remote add origin https://github.com/lowanfft/razryad-edu.git
   git push -u origin main
   ```

   Если Git потребует настроить автора, используй:
   `git config --global user.name "Имя Фамилия"`
   `git config --global user.email "email@пример.ru"`
   и повтори команду `git commit` и последующие команды.
   **Альтернатива:** запусти `PUBLISH_GITHUB.cmd` двойным щелчком.
4. Открой https://github.com/lowanfft/razryad-edu → **Settings → Pages**.
5. **Build and deployment:** `Source = Deploy from a branch`, `Branch = main`,
   папка `/(root)`, нажми **Save**.
6. Дождись появления в Pages ссылки **Visit site**. Обычно итоговый адрес:
   https://lowanfft.github.io/razryad-edu/

Если GitHub уже содержит коммиты, сначала клонируй репозиторий и скопируй
файлы сайта в эту папку, затем сделай `git add`, `git commit`, `git push`.

**Для преподавателя:** исходный код и история коммитов — в репозитории GitHub,
работающая статическая версия — по ссылке GitHub Pages. Это основные этапы ПР6.

## Почему именно так

В ПР6 предусмотрена публикация статического HTML/CSS/JS-сайта через
GitHub Pages. GitHub Pages не запускает Node.js и не предоставляет SQLite.
Поэтому прежняя полноценная версия с Node.js/SQLite остаётся отдельным
локальным вариантом. Здесь нет сломанных запросов к `/api` или пустой панели
Supabase: тест и анкета сохраняются локально в браузере, о чём честно написано на страницах.
