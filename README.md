# РАЗРЯД — интерактивный образовательный сайт

Учебный проект по системам счисления (HTML5, CSS3, JavaScript) и практические работы по серверным технологиям: Express.js, REST API, SQLite, SQL и Fetch API.

## Публичная и локальная версии

- **GitHub Pages:** корневые `index.html`, `quiz.html`, `playground.html` и другие статические файлы открываются через GitHub Pages. Данные теста и анкеты в опубликованном варианте хранятся в `localStorage` посетителя.
- **Полное веб-приложение:** папка `public/` содержит клиентскую часть локального приложения. Сервер раздаёт её через Express. В этом режиме заметки, результаты тестов и анкеты сохраняются в SQLite.

GitHub Pages не запускает Node.js и SQLite. Поэтому серверное приложение необходимо запускать на компьютере, а не по ссылке GitHub Pages.

## Требования и запуск

- Node.js 22.5 или новее, установленный `npm`.
- При первом запуске требуется интернет для установки пакетов.

В корне репозитория:

```powershell
npm.cmd install
npm.cmd start
```

В браузере откройте http://localhost:3000 . Для Windows также есть `START_WINDOWS.cmd`.

Сервер слушает только `127.0.0.1`. Остановка: **Ctrl+C**. После первого запуска автоматически создаётся файл `blog.db`. Он хранится локально и исключён из Git через `.gitignore`.

## ПР8: Express и временное хранилище

```powershell
npm.cmd run start:pr8
```

Используется `server-pr8.js`: статические файлы из папки `public`, `express.json()`, массив записей в оперативной памяти, маршруты GET, POST, PATCH и DELETE. После перезапуска сервера новые заметки исчезнут. В этом демонстрационном режиме результаты тестов и анкеты также хранятся только в памяти сервера.

## ПР9–10: SQLite и Fetch API

```powershell
npm.cmd start
```

Работает основной `server.js`: создаёт SQLite-таблицы `posts`, `quiz_results`, `feedback`, выполняет параметризованные SQL-запросы и обслуживает API. В `posts` при первом создании пустой базы добавляются две примерные учебные записи.

На странице `/notes.html` записи загружаются через `async/await` и `fetch()`, работают живой поиск, создание, лайки и удаление. Значения при добавлении проверяются и в браузере, и на сервере.

Проверка: создать заметку, обновить страницу, перезапустить сервер, проверить, что запись осталась. Откройте `blog.db` в DB Browser for SQLite и просмотрите таблицу `posts`. Результаты тестов и отзывы будут в `quiz_results` и `feedback`.

## Маршруты REST API

| Метод и путь | Назначение |
|---|---|
| `GET /api/posts` | Получение всех заметок |
| `GET /api/posts/:id` | Получение одной заметки |
| `POST /api/posts` | Добавление заметки (HTTP 201) |
| `PATCH /api/posts/:id/like` | Лайк (SQL UPDATE) |
| `DELETE /api/posts/:id` | Удаление заметки |
| `POST /api/results` | Сохранение результата теста |
| `POST /api/feedback` | Сохранение анкеты |
| `GET /api/dashboard` | Локальная статистика |

Валидация данных на сервере не допускает некорректных значений, SQL-запросы используют плейсхолдеры `?`, пользовательский текст выводится на странице безопасно через `textContent`.

## Автоматические проверки

```powershell
npm.cmd test
npm.cmd run test:pr8
```

Проверяются API-маршруты, статусы ответов, серверная валидация, сохранение тестов и отзывов. Для SQLite-тестов используется отдельная временная база данных. Выполняйте тесты после установки пакетов.

## Структура проекта

```text
index.html, quiz.html, ...  GitHub Pages (статическая версия)
server.js                 Полный Express + SQLite
server-pr8.js             Демонстрация ПР8 с массивом в памяти
package.json              Зависимости и команды запуска
public/                   Клиентская часть локального приложения
  notes.html              Заметки и асинхронный Fetch API
  js/notes.js
  index.html, quiz.html, playground.html, ...
tests/                    Тесты API
```

## Ограничения

Локальное приложение рассчитано на демонстрацию с собственного компьютера. Страница `/admin.html` показывает записи локальной базы без авторизации: не размещайте сервер в публичном интернете без внедрения аутентификации и разграничения доступа. В репозитории не должны находиться `blog.db`, `node_modules`, файлы `.env` и ключи доступа.
