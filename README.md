# РАЗРЯД — интерактивный урок «Системы счисления»

Образовательный веб-ресурс на HTML5, CSS3 и JavaScript для изучения позиционных и непозиционных систем счисления.

## Разделы

- **Урок** (`index.html`): теоретические материалы, поиск по темам, фильтрация, конвертер, двоичный конструктор и тренажёр.
- **Игровая лаборатория** (`playground.html`): пиксельный редактор 8 × 8 с двоичным и HEX-кодом, импортом битов и PNG-экспортом; квест из четырёх задач.
- **Тест** (`quiz.html`): итоговая проверка знаний с пояснениями.
- **Обратная связь** (`feedback.html`): оценивание учебного ресурса.
- **Мои результаты** (`admin.html`): результаты и отзывы, сохранённые в текущем браузере.

## Технологии

HTML5: семантические элементы и доступные формы.

CSS3: блочная модель, Flexbox, Grid, медиазапросы, адаптивная типографика, светлая и тёмная темы. Общие правила в `style.css`, стили новых интерактивных компонентов — в `games.css`.

JavaScript: DOM, события, динамический рендеринг, обработка ввода и `localStorage`.

## Запуск и публикация

Статические файлы находятся в корне репозитория. Сайт можно открыть через расширение Live Server или опубликовать через GitHub Pages из ветки `main`, каталога `/(root)`.

Адрес проекта: https://lowanfft.github.io/razryad-edu/

Данные тестов, отзывов и игрового прогресса хранятся локально в `localStorage` браузера; общая серверная база данных не используется.
