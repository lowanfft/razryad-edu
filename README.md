# РАЗРЯД — интерактивный урок «Системы счисления»

Готовый образовательный HTML5-проект: адаптивная вёрстка, семантическая структура, CSS Flexbox, интерактивный JavaScript, тестирование, анкетирование, Node.js API и реальная база SQLite.

## Быстрый запуск на Windows

1. Распакуйте архив в отдельную папку.
2. Самый простой способ: дважды нажмите на **`START_WINDOWS.cmd`**. Сервер запустится в отдельном окне командной строки. Можно также открыть папку в **Visual Studio Code** и запустить через терминал.
3. Если используете VS Code, откройте терминал (**Терминал → Создать терминал**).
4. Выполните:

   ```powershell
   npm.cmd start
   ```

5. Откройте **http://localhost:3000**.
6. Чтобы остановить сервер, нажмите **Ctrl + C** в терминале.

Нужен **Node.js 22.5+** (установленная у вас версия 24.21.0 подходит). Команды `npm install` **не требуются**, потому что используются только встроенные модули Node.js. Если обычная команда `npm` заблокирована политикой PowerShell, `npm.cmd` работает без изменения политики.

**Не используйте Live Server для полной проверки проекта.** Он откроет HTML и JavaScript, но не запустит Node.js API: данные тестов и отзывов в SQLite не сохранятся.

## Страницы

- **`/`** — главная, теория, живой поиск по шести темам, фильтры, раскрытие карточек, локальные лайки, интерактивный конвертер и двоичный конструктор, мини-практика.
- **`/quiz.html`** — итоговый тест с десятью вопросами, проверкой каждого ответа, объяснениями, итоговым результатом и отправкой его на сервер.
- **`/feedback.html`** — анкета: полезность, понятность, комментарий, согласие на сохранение.
- **`/admin.html`** — демонстрационная панель статистики, читающая реальные записи из SQLite. По умолчанию API статистики разрешён только с компьютера, где запущен Node.js.

## Где база данных

После первого запуска появится файл **`data/education.db`**. В нём две таблицы: `quiz_results` и `feedback`. Запросы на запись выполняются по маршрутам `POST /api/results` и `POST /api/feedback`; просмотр статистики — `GET /api/admin/stats`, `GET /api/admin/results` и `GET /api/admin/feedback`.

Данные не выдуманы и не хранятся только в браузере: их принимает сервер, проверяет и записывает в базу SQLite. Настройки темы и отметки «Полезно» сохраняются отдельно в локальном хранилище браузера (`localStorage`).

## Как используются материалы курса

| Материал | Реализация |
|---|---|
| ПЗ2 и ЛК2 (CSS, блочная модель) | Внешний `style.css`, CSS-селекторы, `margin`, `padding`, `border`, `box-sizing`, псевдоклассы, правильная специфичность |
| ПР3 (Flexbox) | Шапка с меню, основная колонка и `aside`, гибкие пропорции и `gap`, перестроение в мобильную одну колонку через `@media` |
| ПР4 и ЛК3 (JS, DOM) | `addEventListener`, `classList.toggle`, переключение светлой/тёмной темы, независимые кнопки «Полезно», раскрытие материала |
| ПР5 (динамический рендеринг) | Массив объектов `lessons`, генерация `<article>` через JavaScript, поиск по заголовку, описанию и содержимому, фильтры по категориям |
| ЛК4 (серверная архитектура) | Node.js, маршруты Web API, HTTP-методы GET/POST, обработка и проверка JSON, SQLite |
| ПР6 (Git / GitHub) | Готовый `.gitignore`, структура проекта для репозитория и описание публикации ниже |

Лекции приведены как **основа реализации**, а не как список упражнений, которые нужно выполнить буквально. Например, вместо счётчика произвольных публичных лайков использована локальная отметка «Полезно» для материалов урока.

## Техническая реализация

- **HTML5**: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `form`, `fieldset`.
- **CSS**: внешняя таблица, переменные, `display: flex`, сетки карточек, адаптивные медиазапросы, состояния `:hover`/`:focus-visible`, тёмная тема.
- **JavaScript**: без сторонних библиотек, объектная модель документа, динамические карточки, живой поиск, формы, `fetch()` для API.
- **Node.js 22.5+**: встроенный `http` и `node:sqlite` (`DatabaseSync`), без установки зависимостей. **Express здесь не используется**, поскольку встроенного HTTP-сервера достаточно для учебной задачи.
- **Безопасность**: сервер проверяет входящие данные, публичная папка отделена от файла базы, админ-данные доступны только с локального компьютера. Для настоящей публикации нужна дополнительная авторизация и политика обработки персональных данных.

## Проверки

```powershell
npm.cmd run check
npm.cmd test
```

Первая команда проверяет синтаксис JavaScript, вторая проверяет работу сервера, сохранение результатов и анкет в базе, а также ответы API.

## Публикация через GitHub

Команды для создания репозитория в папке проекта:

```powershell
git init
git add .
git commit -m "Initial commit: RAZRYAD educational site"
git branch -M main
```

После создания пустого репозитория на GitHub можно выполнить команды, которые GitHub покажет для загрузки существующего репозитория (с настоящим адресом своего репозитория).

**Важно о GitHub Pages:** GitHub Pages публикует **только статические файлы**. На нём будут работать страницы HTML, CSS, JavaScript, поиск, конвертер и локальные задания, но **не запустится `server.js` и не будет работать сохранение в SQLite**. Для полного веб-приложения нужен хостинг Node.js с постоянным хранилищем базы. Не выкладывайте `data/education.db` в публичный репозиторий.

## Что показать на защите

1. Откройте сайт в браузере и уменьшите окно до ширины смартфона: двухколоночная вёрстка перестроится.
2. Переключите светлую/тёмную тему, обновите страницу: выбор сохранится.
3. Найдите «египетская» в каталоге, раскройте текст, отметьте «Полезно».
4. Переведите 45₁₀ в 101101₂, переключите разрядные биты, выполните мини-задание.
5. Пройдите тест и отправьте отзыв.
6. Откройте `/admin.html`: увидите реальные записи. Можно показать файл базы `data/education.db` в расширении SQLite для VS Code.
